# Contributing to Smart Personal Finance Analyzer

Welcome! We are excited to have you contribute.

## How to Contribute
1. Fork the repository and create your branch from `main`.
2. Follow our coding standards and architecture boundaries (Presentation -> Platform -> Application -> Domain -> Infrastructure).
3. Ensure all tests pass by running `npm test` inside `finance-app/`.
4. Submit a Pull Request.

## Code of Conduct
Please review and adhere to our [Code of Conduct](CODE_OF_CONDUCT.md).
