# Progressive Web Application (PWA) Platform
# Platform Guide

## Overview
The platform exposes service-worker integration, enabling offline access, push messages, asset pre-fetching, and background synchronization queues.

## Specifications
- **Service Worker**: `finance-app/public/sw.js`
- **Manifest**: `finance-app/public/manifest.json`
- **Features**: Standalone app display-mode detection, in-app chromium installation prompting, postMessage event synchronization updates.
